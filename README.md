# Challenge_Friend

# Funcionalidades del proyecto

- **Añadir Nombres:** Para añadir nombres deberás escribir en la entrada y luego pulsar el botón "Añadir". Acto seguido, aparecerán abajo en letra negra todos los nombres que se hayan ingresado.

- **Validación de Entradas:** No está permitido ingresar ningún carácter especial o número. En caso de hacerlo, aparecerá un cartel indicando el error.

- **Sortear Amigo:** Para elegir un nombre al azar, puedes pulsar el botón "Sortear Amigo", donde se elegirá un nombre y aparecerá de color verde arriba de dicho botón. Cabe aclarar que si no ingresas ningún nombre, no aparecerá nada.
